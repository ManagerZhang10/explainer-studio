# 故障判断与恢复

旧事故与当前实现分开理解，不将历史修复建议作为现行接口。

| 现象 | 当前判断与恢复 |
| --- | --- |
| Python 执行 .sh | 解释器错误；用主文档四条 .py 命令，shell 脚本交给 shell |
| 字幕三句堆叠 | 当前只有 .on，其余 .gone；核查是否加载旧页面，不恢复 past 规则 |
| 长字幕越界 | 英文词/括号保持整体可超 16；精简术语后重建，查 caption_outside |
| 时间轴极短 | duration_of 为秒，speech_ms 乘 1000；marks 存秒，WAAPI 局部时间毫秒 |
| 改稿声音不变 | 当前 key 含口播 md5 前 8 位；查正确脚本/key，重建页面 |
| 换声音/速率复用旧音频 | key 不包含这些配置；隔离该条音频与 marks 后重合成，不清全部 work |
| mp3 有、marks 缺 | 当前非空 mp3 与 marks 同时存在才复用，否则重新合成；无效 marks 内容仍需核查 |
| cue 着色/框选不对 | 节点应始终可读；核查实际短语、caps 累积匹配、重复命中、reveal_times；未命中等分近似 |
| 时长超范围抛错 | 当前在 render 前校验实际 total；改稿重合成，不拉伸音画、不改门禁 |
| 同 DAY 锁冲突 | 等原进程退出重试，不删除锁文件或开第二 writer |
| audit 读旧页/半页 | audit/gen_script 不持 daylock；同 DAY 等构建完成再审查 |
| partial 无新片 | 编码失败；正式旧片保留，查日志再重试，不交 partial |
| 尺寸不符 | 当前读 --scale 数值；用 0.6666666667，ffmpeg -hide_banner -i 核验 |
| 有线无箭头 | 查 #ar marker、端点、layoutArrows 与静态 path；audit 不覆盖全部 |
| 图流程错误 | 按来源纠正 nodes/links，不靠补装饰箭头修语义 |
| seek 截图变化 | 全部 WAAPI pause、字体加载、墙钟动画及资源检查 |
| 缺帧 | 当前少于预期 98% 抛错；仍核查连续编号及 ffmpeg 退出 |
| generic 仍出现课程尾卡 | next_title 缺失或为空会回退 chapters.next_card；显式填非空 next_title/next_hint |
| generic 尝试读取课程资源 | 至少一个 scene 没有非空 visual，触发混合模式；检查全场景 visual |
| 同来源多场画面覆盖 | 全 visual 现按 scene 独立 slot，source_slide 保留来源；检查是否用旧版或混合模式 |
| 独立项目 audit 找不到多章 | 支持 --project-dir，但省略 days 仍检查 1–14；单条明确传 1 |

## CPU 与后台

远端生成和声音不等于本地零 CPU：浏览器、图片处理与 ffmpeg 都消耗 CPU。重渲染最多 2 路，包含 audit；同章串行，不复用旧 5 路时间表。本机不跑 Whisper/MLX 等 AI 推理，需要转录走远端并核实时间戳格式。

长任务用当前环境持久后台机制，记 PID、DAY、日志，只 tail 状态。无持久机制才用已验证任务管理器；先核实 Python 解释器装有 edge_tts、Playwright、Pillow，ffmpeg/Chromium 可用。不假定 launchctl PATH 和交互 shell 一致，不写死别的机器解释器。

## 远端与缓存

证书失败检查解释器和受信 CA，不关闭校验；证书优先用 certifi，其次系统证书包。凭据只从 config 的 `[secrets] env_file` 读，不复制或打印。

DeepSeek 空正文可能是 reasoning 用光预算；当前 max_tokens 16000、最多 4 次远端尝试、10/20/30 秒退避、timeout 1800 秒。最终失败报告原因，不无限重试。脚本输出校验另最多 3 次。不固定宣称未实查的远端转录格式。

## daylock / atomicmp4

构建全程持 work/locks/dayNN.lock，渲染会清该章 frames。实际声音 total 在写新 HTML/timeline/SRT 和 render 前校验 120–180 秒；超限时旧页面可能仍在，不能误当新稿成果。

编码到 out/.dayNN.partial.mp4，mux 成功后 os.replace 到正式片；同名旧片被替换，改标题可能留下旧片，以实际返回路径交付。原子替换不证明事实和音画质量，仍需 ffmpeg 元数据检查、完整解码及抽听。

daylock 只按 DAY，不限制跨章全机并发，不保护 gen_script/audit。同 DAY 完整串行、全机重渲染最多 2 路的操作调度必须单独执行。

--project-dir 将锁、音频缓存、中间件和正式输出隔离到指定项目；day 可选默认 1，不同项目各用自己的 day01.lock。同项目同 DAY 仍须串行。audit_pages 支持 --project-dir，检查失败退出 1；run_batch/verify_delivery/write_index 当前只处理默认课程目录，不接受 project-dir 或 --script，不能靠换 cwd 切换硬编码路径。
