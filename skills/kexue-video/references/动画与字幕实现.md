# visual、字幕、离线与逐帧

补充机制图：`visual.kind="patches"` 配 `grid`（2–8）画图片网格、位置序列和向量，`asset` 可指绝对路径本地图片，读取后内联；省略图片则用明确的教学像素示意。`visual.kind="timeline"` 配 `frame_count`（2–8）、`selected_frames`（零起点索引数组）及可选 `event_frame` 表达抽帧与漏采。示意帧不能标成真实视频帧，也不能冒充实验配置。主张真实输入输出时使用可追溯素材，另写清来源。

字幕会保护常见中文技术词、英文词及括号组。句级边界可能相邻重叠，构建器把后块开始时间移到前块结束时间，导出的 SRT 和 timeline 不重叠；这仍不是逐字强制对齐。核验开始早于结束、相邻边界有序，并实查语义断句。

独立项目可用 `end_label` 指定尾卡标签；例如同一知识点收束设 `end_label="带走这一点"`，不要把总结误标为下一集。

实现来源是项目 pipeline 的 visuals.py、tts.py、build_video.py、audit_pages.py；以下是此次核对的现行合同。

## scene.visual 字段

| 字段 | 当前合同 |
| --- | --- |
| title | 必填，短标题 |
| subtitle | 可选，一句解释 |
| nodes | 必填，2–5 个，即使 matrix 也先校验 |
| node.label | 必填，短标签，过长自动缩小字体 |
| node.detail | 可选字符串，当前每 10 字符折一行，保持简短 |
| node.color | gray/blue/purple/orange/green，未知回退 blue |
| node.cue | 可选，真实口播短语；缺省用 label |
| links | 数组，每项 [source,target] 或 [source,target,label] |
| example/note | 初学者例子 / 边界说明 |
| kind/labels | kind=matrix 是特定图文配对矩阵，labels 默认猫、路牌、早餐 |

links 索引从 0 开始，整数、不自连、不越界；课程来源 slide 从 1 开始，勿混用。nodes 横排，相邻直线、跨节点上方折线，关系方向须真实。

全 visual（sourcefree）模式每个 scene 独立分配渲染 slot 编号，不按来源 slide 去重。输入 scene.slide 保留为 timeline 的 source_slide；timeline.slide 则是渲染页面位置。多个 scene 可来自同一个 slide，仍分别保留自己的 visual、口播和 cue，不覆盖前一场。混合原页模式仍按来源页选择页面，不应将 sourcefree 的重复来源支持推广到混合模式；课程生成器本身也仍拒绝重复选页。

节点并排不是流程。CLIP 图像/文本编码是两条分支到比较，不是“图像 → 文本 → 编码器”。数据流、控制、训练目标、相似度比较要明确区分。横排简图表达不清的多分支图，用经过审核的原页面或另做布局适配，不编错误链路。矩阵是概念配对，不是实测分数或任意矩阵工具，优先少量 labels 并检查溢出。

## cue 与 reveal_times

构建器从 visual.nodes 取 cue，缺省为 label；visuals 自动生成唯一节点 reveal ID（matrix 为对角 cell ID）。普通图按节点顺序组织；matrix 模式需让 nodes 的 cue 数量、顺序和对角 reveal 一致，当前实现不会自动替你校正。

build_timeline 根据远端 TTS marks 生成 caps，再累计去空白字幕文本匹配 cue。命中时用**当前匹配完成的字幕块起点减场景起点，再提前 0.20 秒，最小 0**作为 reveal_times。跨字幕的短语可被累计匹配，但不等于精确找到词首，重复短语会命中最早出现。

未匹配时降级为 `index * speech * 0.65 / max(1, reveal_count)` 的等分近似。当前 timeline 为每个 reveal 生成时间，无 cues 的原页也走该近似；runtime 的场景 70% 等分是缺少对应时间时的后备。检查导出的 timeline.json，试听节点着色和框选时刻；不能把近似称为精确词级对齐。cue 要短、独特、实际念出，不随意使用未口播的屏幕标题。

## 句级 marks 与当前字幕

edge-tts 收集 WordBoundary/SentenceBoundary，保存 offset/duration/text，100ns ticks 除以 1e7 转秒。当前使用句级 marks，接入其他版本先查真实事件，不能保证任意服务是句级。

每个 mark 文本 split_captions(max_chars=16)，块内按字符比例分配该 mark 时长，再加场景起点。缺 marks 回退整段语音区间近似；逐字高亮也是比例估计。句级边界来自声音，句内切块和高亮不是逐字强制对齐。

完整英文/数字 token、（）或() 括号不可拆。**16 是常规块目标**，长英文和长括号可整体超过，标点也可能跟随前块导致超限。遇到超长实查屏内宽度，必要时简化口播术语，不能拆词凑数。

runtime 只显示当前块 .on，其余 .gone；不显示上两句。gap 可能保留末块，首 mark 前可先显示首块，不能声称句间严格清屏。当前白字深底胶囊 42px，页面下 padding 190px、gloss bottom 106px、字幕 bottom 26px。旧黄描边、三句堆叠和 392/296px 留白不再适用。

## 离线与完整箭头

visual links 使用 marker-end=url(#ar)。所有 scene 有 visual 时，构建使用内置 BASE_CSS、MARKERS 和 VISUAL_RUNTIME，不读取课程 deck 或图片，layoutArrows 为无操作函数，因为简图已生成静态 path。混合模式从课程 deck.html 复制 marker 与 boxIn/layoutArrows JS，原页动态 [data-from][data-to] 连线在激活时布局。两种模式都确认 path 和 marker 可见；原页还要确认端点存在。

全 visual 模式用内置 CSS 和 SVG，无课程图片依赖；仍检查本机字体、离线渲染和 marker。混合模式内联 work/deck.css 与课程 slides/_base/extra.css，双引号 src/href 的 media/ 资源转 data URI，缺文件抛错；其他 CSS url、远端字体和属性不自动全面离线化。检查 HTML 和浏览器请求，离线无坏图、缺字和箭头消失。

HTML 页面用于逐帧渲染，不承诺自带声音播放器；声音另在成片合并。--html 也可能发远端配音请求。构建成功导出 page.html、timeline.json、captions.srt 到项目 work/video/dayNN/，SRT 使用同一 caps 时间轴。--project-dir 切换 work/out/scripts、配音缓存和 daylock 路径，--script 指定读取的 JSON。

## 暂停 WAAPI 与逐帧

切场景 cancel 旧 animation，创建后全部 pause。seek(t) 设场景内 `currentTime = max(0, (t - scene.t0) * 1000)`，逐帧调用 __seek(frame/30) 后截图，先等 __ready 与 document.fonts.ready。

当前整页 kb=1，不推近。大字节点从该场景第 0 帧始终可读，不靠隐去、缩放或 0.45 压暗制造逐步揭示。标题仍有错峰 WAAPI 入场，创建后暂停，按 seek 寻址。

普通节点矩形按 cue 的 reveal_times 从浅灰 rgb(245,245,245) 过渡到原语义色，持续 420ms。seek 的 JS 计算 `progress = clamp((local_ms - delay_ms) / 420, 0, 1)`，逐 RGB 通道插值后写入不透明 fill，而非改变节点透明度；文字和关系始终可读。原色保存在 originalFill，回寻时按同一时间重新计算，不依赖播放累积状态。

高亮框指向最近一个已到 reveal_time 的节点；首 cue 前隐藏，场景约 86% 后隐藏，让末段保持完整图。矩阵的配对和不配对格全显示，cell 不进入节点渐变着色分支，框选按 cue 跟随对角配对格。句级 marks、句内比例分配与 cue 匹配仍有近似，不称逐字精确对齐。

不能依赖墙钟动画或截图自动快进。Chromium 渲染已加 --disable-frame-rate-limit 和 --disable-gpu-vsync，截图仍按 frame/30 寻址；这不改变输出 30 fps，没有测速证据不承诺渲染速度。

audit 在每场景 5%/50%/92% 检查，并回寻同一时间比较截图。查看 errors、deterministic 和 observations：overflow 空、empty_arrows/broken_images=0、caption_outside=false、caption_lines 至多 1（有字幕应为 1）、running_animations=0。audit 不审语义，不全面检查遮挡、静态 links 或所有 marker，必须人工看起始、英文长句、每条连线与末段，并抽听。

audit_pages.py 接受 DAY 列表及 --project-dir PATH，独立项目用 `python3 audit_pages.py 1 --project-dir /tmp/demo`，报告写该项目 work/qc/repaired/。省略 DAY 默认 1–14，即使指定 project-dir 也一样。errors 非空、deterministic=false 或 observations 出现 overflow、空箭头、坏图、字幕越界、运行中动画、字幕块超过 1，都会退出 1；通过才继续渲染。
