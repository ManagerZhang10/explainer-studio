# 新 doc 的独立项目入口

尾卡标签可用 `end_label`：有明确下一集才用“下一支”，本条收束用“带走这一点”。`next_title`/`next_hint` 是显示文案；独立 JSON 省略它们时使用通用练习收尾，不回退 VLM 课程。切块机制可用 `kind="patches"`，视频采样可用 `kind="timeline"`，详见动画说明。

## 当前已支持的能力

build_video.py 使用 argparse：day 可选，默认 1；支持 --script PATH、--project-dir PATH、--html、--scale FLOAT、--keep。所有 scenes 都有非空 visual 时，用内置 BASE_CSS/MARKERS/VISUAL_RUNTIME，不读取 VLM deck、图片、work/deck.css 或课程 extra.css；新 doc 可在独立项目直接出片，无需修改硬编码路径。

gen_script.py 仍只支持课程 docs/track_a/dayNN.md 和章节页面，没有任意 doc 输入。新 doc 的口播与 JSON 由 Agent 按来源手工构造并审核，不把 build_video 的 generic 渲染能力说成任意资料自动生成能力。

只要有 scene 缺 visual，就走混合原页模式，仍需要课程页面/资源；独立项目优先全 visual。--project-dir 只是工作/输出目录，并不是任意 deck 路径参数。

## 来源和脚本准备

1. 记录来源路径/版本/段落、受众、唯一知识点、允许主张和例子边界。PDF 漏图或公式时补证。
2. 按 [口播稿规范](口播稿规范.md) 构造 title/hook/scenes/outro；scenes 非空，每场景 narration、来源 slide 和完整 visual。全 visual 模式不需要对应 VLM 页，来源可重复，构建器为每场独立编号并在 timeline.source_slide 保留来源。构建器不会代做全面 schema 或事实审核。
3. nodes/links/cue 使用 [实际 schema](动画与字幕实现.md)，cue 为真实口播短语，审查 reveal_times 的匹配和降级。
4. 设置 series/question/next_title/next_hint。--script 时 series 默认“知识点讲解”，question 缺省取首场 subtitle。**next_title 必须非空**，否则仍回退 chapters.next_card 的课程尾卡；无需下一集时可填本条总结，而非虚构下一条。

项目路径通过现有 --script 和 --project-dir 配置，无需虚构配置文件 CLI 或先实现 adapter。声音 provider/rate、任意 deck 路径或模板参数不是现有 CLI；需要这些扩展时另外实现，不能将其称为已支持。

## 真实命令

先由 Agent 创建并审核 /tmp/new.json（只是示例路径），在 pipeline 目录运行：

```bash
cd <explainer-studio 仓库>/studio/lecture
python3 build_video.py 1 --script /tmp/new.json --project-dir /tmp/demo --html
python3 audit_pages.py 1 --project-dir /tmp/demo
python3 build_video.py 1 --script /tmp/new.json --project-dir /tmp/demo --scale 0.6666666667
```

按顺序检查每条退出状态，audit 失败不能继续 render。day 省略默认为 1，但 audit 省略 days 默认 1–14，所以单条要明确传 1。正式项目替换 /tmp 为实际持久路径。

--project-dir 将 ROOT/work/out/scripts、TTS 音频缓存和锁切到项目内；--script 指定 JSON，不需要将它复制到 work/scripts。当前产物：
- /tmp/demo/work/video/day01/page.html、timeline.json、captions.srt、audio/voice.wav。
- /tmp/demo/work/audio/：远端声音及 marks 缓存。
- /tmp/demo/work/locks/day01.lock：项目内 daylock。
- /tmp/demo/work/qc/repaired/audit.json、day01_contact.png：审核证据。
- /tmp/demo/out/day01_标题.mp4：正式成片；编码临时文件为 .day01.partial.mp4。

--html 仍会请求缺失配音，实际 total 必须 120–180 秒，否则在写新页面和 render 前抛错；改稿再合成，不硬拉伸音画。独立项目之间锁隔离，但全机重渲染仍最多 2 路，同项目同 DAY 串行。

## 审核与交付限制

audit_pages 已支持 --project-dir，页面错误、确定性失败或观察异常退出 1；仍需人工核对事实、静态 links、marker、遮挡、cue 和声音。全 visual 离线不代表首次配音离线，也不保证每台机器字体一致。

run_batch、verify_delivery、write_index 目前只支持默认课程目录。不能给它们编造 --project-dir 或用默认课程报告代验新项目。独立成片用 [制作参数表](制作参数表.md) 中 ffmpeg 元数据及完整解码命令检查，比较实际 timeline，保留结果和抽听记录。当前不依赖 ffprobe。

确认来源确实被读入、页面无旧课程标题/尾卡、未写到课程输出；实际 1280×720/30fps/120–180 秒、音轨正常，timeline/SRT 与视频同步后交付实际项目路径。
