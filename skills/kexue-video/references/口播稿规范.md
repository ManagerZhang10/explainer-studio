# 单一知识点、口播与事实审核

## 选点与初学者例子

先写一句“看完能解释……”。若含多个独立机制，缩成一个。Day02 可选“为什么图片先变成视觉令牌”，不同时讲完训练、接口和推理成本。只保留支撑答案的必要前提。

当前课程生成器 SYSTEM 面向“会 LLM、没系统学过 VLM 的工程师”。面向更初级受众时须人工补前提，不能假设已自动适配。用具体问题开头，逐步解释，结尾回答开头；反常识结论需可核实。下一集仅在确有下一集时提。独立脚本用非空 next_title 与 next_hint 配置尾卡；next_title 缺失或为空时回退 chapters.py 的课程尾卡。

例子要能跟着走：输入是什么，做了什么，产物是什么，为什么有用。若讲义支持图像切块，可用“一张猫图 → 小块 → 每块的向量”解释表示变化；不要说“每块认出一个物体”，不要编造块数和维度。例子同时进入口播和 visual.example；类比说明对应关系和失效边界，不能当实验结果。

## 事实审核

配音前逐场记录：主张、来源文件/段落、支持证据、对应节点/连线。数字、shape、模型名、比较、因果、训练/推理区分重点核查。不支持的删掉或保守改写；需要新事实先取得原文。讲义是当前来源，页面是选页和元素 ID 线索；讲义疑似错误或过时也要指出并核实。

一句一个意思，标题提出问题，口播解释原因，不全程念标题。英文首次中文解释加括号原词，后续中文简写。公式读成自然语言，不在口播塞 LaTeX。

## 当前生成器合同

`studio/lecture/gen_script.py` SYSTEM 是实际 prompt，此文档不会自动覆盖它。DeepSeek V4 Pro 用 urllib，密钥运行时只从 config 的 `[secrets] env_file` 读，max_tokens 16000，正文取 content，不取 reasoning_content。

| 项 | 当前行为 |
| --- | --- |
| 提示总长 | 580–720 汉字 |
| 实际机器放行 | 580–720 汉字，不保证时长 |
| 每页提示 | 40–110 汉字、2–4 句 |
| hook/outro 提示 | 各 25–45 汉字 |
| scenes | 3 到章节页数 |
| slide | 章节内从 1 开始，不越界、不重复 |
| reveal | 过滤成真实页面 ID 存到 _reveal |
| 校验重试 | 最多 3 次 |

汉字计数：`sum(1 for ch in text if '一' <= ch <= '鿿')`，英文标点不算。预算不等于片长；声音合成后按真实时长检查 120–180 秒。超限改稿，不硬拉伸。

## 脚本 schema 与 visual 示例

顶层必需 title/hook/scenes/outro；scenes 必须非空，scene 必需 slide/narration。reveal 和 _reveal 为原页 ID；visual 可替换选中的页。有 visual 时构建器自动生成场景唯一 ID 和 _reveal，不用原页 ID 控制简图。所有场景都有 visual 时不依赖课程页，slide 记录来源编号，允许多场共用同一来源；渲染器为每场独立分配 slot，并在 timeline.source_slide 保留原值。无课程来源时可用正整数编号。混合模式则需有效课程页号。生成器不会自动产出 visual，课程生成后审核添加，新 doc 由 Agent 手工构造完整 schema。

generic 可选顶层字段：series 为系列名（--script 默认“知识点讲解”），question 为开场设问（缺省取首个 visual.subtitle），next_title/next_hint 为尾卡内容。独立项目应显式填这些字段，尤其 next_title 非空，避免课程默认尾卡。构建器不替代来源审核，也没有完整的生成器 schema 校验。

下面仅示例一个 scene，不是完整时长脚本。课程生成器需至少 3 场且来源页不重复；手工 generic 脚本场景数量按讲解选择，须非空、全 visual 并通过事实与实际时长审核，来源 slide 可重复：

```json
{
  "title": "图片怎样变成令牌",
  "series": "视觉表示入门",
  "question": "图片为什么要先变成向量？",
  "next_title": "记住表示变化",
  "next_hint": "向量不是物体标签",
  "hook": "这里填写已审核的开场。",
  "scenes": [{
    "slide": 3,
    "narration": "一张猫图先切成小块，再把每个小块映射成向量。向量并不等于识别出的一个物体。",
    "reveal": [],
    "_reveal": [],
    "visual": {
      "title": "先切块，再表示",
      "subtitle": "看每一步的产物",
      "nodes": [
        {"label": "图片", "detail": "一张猫图", "color": "gray", "cue": "一张猫图"},
        {"label": "小块", "detail": "按空间切分", "color": "blue", "cue": "切成小块"},
        {"label": "向量", "detail": "表示每个小块", "color": "purple", "cue": "映射成向量"}
      ],
      "links": [[0, 1, "切块"], [1, 2, "映射"]],
      "example": "跟着猫图看表示变化",
      "note": "向量不等于已识别的物体"
    }
  }],
  "outro": "这里填写回答开头的结尾。"
}
```

cue 必须是 narration 中真实出现的短语，不用没念过的标题。参考 [动画与字幕实现](动画与字幕实现.md) 检查匹配、降级与 reveal_times。更改口播后重新计算 _total_cn；_day、_attempts 是生成元信息。再次 gen_script 会覆盖人工 visual。
