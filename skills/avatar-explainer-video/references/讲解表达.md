# 讲解表达：原理课、系列课怎么讲清楚

适用于「把一个模型或机制讲透」的系列讲解视频，例如多模态原理第 N 课。每一条都是用户在逐页、逐秒审片时纠正过的问题。写稿和写 `scenes.js` 之前先读一遍。

## 一、先讲义，后视频

1. **先做讲义 keynote，逐页过完再做视频。**视频是讲义的压缩：顺序照讲义，每页压成一到三句。讲义没定稿，不写口播稿。
2. **停两次给用户看。**先交大纲（段落、每段讲什么、画什么、时长估计），确认后再交口播稿全文，确认后才配音和对口型。每一轮改稿都会重做配音和对口型，返工最贵。
3. **改稿攒齐再重配。**用户逐条提意见时，先把整轮意见收齐、一次改完，再只重配受影响的句子。边提边配会让对口型重复付费；有一版约一半的对口型费用花在了重复生成上。

## 二、结构与叙事

1. **每集自成一体。**不说「上一集讲过」「前面说过」。开头先交代本集的输入和输出，再按「经典结构 → 当前模型 → 最新变化」展开。
2. **开场 5 秒内讲清这一集讲什么。**只说一句：「系列名第 N 课，主题：一个问题？」，例如「多模态大模型原理第二课，视觉编码：一张图片，怎么变成大模型能读的向量？」。第一帧就是封面；这句话期间画面要有一个最小动效（比如一张图转成一串向量），不能停着。
3. **每一步先报步骤名，再说原因。**写成「第五步合并。要合并，是因为……所以……」，不要先抛问题再说「第五步」。页面标题同理：先说要达成什么，再说受什么限制，最后说怎么做。
4. **节与节之间用「但是」接。**上一步留下的问题，就是下一步出场的理由。
5. **结尾 = 回顾 + 一句预告 + 欢迎关注。**回顾每步一个短语，并带上它的作用（例如「加位置知道在哪」，不只说「加上位置」）。预告一句话；「欢迎关注」不能删。
6. **相近内容合并成一页或一段。**同一个概念拆成好几段（视频总览、怎么分组、为什么两帧）就合并；两段都讲注意力就合并。没有信息量的实测、和主线无关的深细节都删掉，深细节放到拓展专题里。

## 三、数字与术语

1. **先定义单位，再报数字。**例如先说「1 个 token = 32×32 像素」，再说「2040 个 token」。同一个东西全片只用一个叫法，不要「格子」和「token」混用。
2. **说清楚数字从哪来。**常数（上下限、预算）给出来源；官方没解释的，就说「官方没说为什么」，不要编理由。推断要标明是推断。
3. **只算本集需要的。**算一张图占多少显存时，不要顺手扯上下文长度。那是下一集的内容，放在这里只会让人困惑。
4. **核对常见误区。**例如「这张表是从某模型原样继承的」：先查原始配置，再决定怎么说。

## 四、画面

1. **图先完整出现，再随口播逐项高亮。**一张图或一张表一出现就是完整的，讲到哪一项，就给哪一项加黄色高亮。不要先空着、再一批字一下子冒出来。
2. **说明文字不能先于它描述的图出现。**先画出两根预算条，再出「两根条一样长」这句说明。
3. **讲具体论文，就秀论文本身。**放论文标题页和原图（ar5iv 页面里的 Figure，通常是 `x1.png`），并在原图上高亮当前讲到的部分。示意猫图只能当辅助，不能单独撑起「讲 ViT 论文」这一句。说到什么就画什么。
4. **机制要画经典结构图，不要只画抽象连线。**
   - 多头注意力：X → 线性层得到 Q、K、V → 切成 h 个头 → softmax(QKᵀ/√d)·V → 拼回 → 输出线性层，标真实维度。
   - 小 MLP 类模块（例如合并器）：画出内部 LN → 拼接 → Linear → GELU → Linear，旁边配一句大白话说明它的作用。
5. **「一块」就画原图中的一小块。**从整图里框出一格并放大，不要拿整张图代表一块。
6. **每句话期间画面都要变化。**动效挂在词上；一整句画面不动，观众就会划走。
7. **对比要让变化一眼可见。**
   - 多代对比表：和上一代不同的格子标黄，没变的格子写灰字「同 X」。
   - 占比对比：画两根并排的柱子（例如参数占 6.6%、token 占 99%），不要只写一行比例。
8. **顶部进度条覆盖全片，命名跟着口播走。**
   - 开场之后的每一段都要在进度条上，包括「经典结构」和「总结」。
   - 只有口播里说了「第 N 步」的段才编号，其余段（经典结构、对比、总结）不编号，也不加 A/B/C 字母。
   - 段名用短词，例如「对比」，不用「三代」。
9. **小窗不能压住主体。**主体需要占满画面时，小窗退场或换位；检查时逐段看静帧。
10. **手机上要看得清。**论文原图、公式、表格在手机上字太小时，放大局部或裁切后再放。

## 五、封面

同一系列的封面保留系列标签、标题字号和配色，主画面换成这一集独有的结构图（比如讲视觉编码就放 ViT 结构图，从下往上读，每层旁边配一个关键数字）。封面不能和上一集长成同一个样子。

## 六、交付前自查

- [ ] 开场一句话，不超过 5 秒，第一帧是封面
- [ ] 每段都是「步骤名 → 原因 → 做法」，段间有「但是」
- [ ] 每张图先完整出现、再逐项高亮；没有文字先于图出现
- [ ] 讲论文时有原论文标题和原图
- [ ] 进度条覆盖全片，编号和口播一致
- [ ] 小窗不压主体
- [ ] 数字和单位前后一致，推断已标明
- [ ] 时长对过目标；超出的话，先告诉用户最长的几段，再问删哪段
