# 画面写法（scenes.js）

`core.js` 先加载，`scenes.js` 后加载，两者共享全局变量。坐标是 1080×1920 像素，时间单位是秒。

## 骨架

```js
ASSETS = { cat: '/assets/cat.png' };          // 预载图片，用 IM.cat 取
TRACKER = { items: ['VAE', '主干', ...], from: () => at('五个零件', 'p03'), to: () => L('p11').start,
            active: t => [下标], done: t => [下标] };   // 顶部「讲到第几个」进度条，可省
SCENE('p01', (t, a, b) => {                     // a = 这句开始，b = 下一场景开始前 0.25 秒；淡入淡出由核心处理
  headline(t, a, b, '01 · 小标签', '黑字结论，', '蓝字关键词');
  const t1 = at('闭源的', 'p01');                // 词在配音里开始的时刻
  const p = pop(t, t1 - 0.1);                   // 0→1 带回弹；ease() 是平滑版
  if (p > 0) { box(48, 490, 984, 236, { al: p }); T('理解', 80, 560, { s: 46, w: 900 }); }
});
PLAN = () => { cue(at('闭源的', 'p01'), 'pop', 0.6); };   // 音效挂词；场景切换的 whoosh 核心自动加
window.PRELOAD = t => [...];                    // 某段要逐帧播放的图片序列（如官方样例视频帧）
```

## 常用函数

| 函数 | 作用 |
| --- | --- |
| `at(词, id, nth)` / `atEnd(词, id)` | 词开始 / 结束的秒数；`L(id).start/.end` 是整句起止 |
| `pr(t, a, d)` `ease(t, a, d)` `pop(t, a, d)` | 从 a 起 d 秒内 0→1：线性 / 平滑 / 回弹 |
| `win(t, a, b)` | a 淡入、b 淡出的窗口系数 |
| `headline(t, a, b, 小标签, 黑字, 蓝字)` | 每段标题，放不下时蓝字换行 |
| `T(文字, x, y, {s, w, c, a, b, f, al})` | 写字，返回宽度；`TT([[字, 样式], …], x, y, 基础样式)` 一行多色 |
| `box(x, y, w, h, {fill, line, lw, r, al, shadow})` | 白卡片 |
| `chip(文字, x, y, {s, h, bg, fg, line, a, k, al})` | 胶囊标签，`k` 是缩放 |
| `arrow(x1, y1, x2, y2, 颜色, 线宽, 进度, {dash, head, al})` | 箭头 |
| `mark(ok, x, y, r, al)` / `strike(x, y, w, p)` | ✓ ✗ 圆标 / 删除线 |
| `img(图, x, y, w, h, {zoom, dx, dy, r, al})` | 等比铺满画图 |
| `noise(x, y, w, h, sigma, seed, {cells, r})` | 块状灰度噪声，sigma 1 全噪声 |
| `stack(n, x, y, w, h, (k, fx, fy, fw, fh) => …)` | 一叠帧（表示视频） |
| `cue(秒, 类型, 增益)` | 音效：tick pop swipe whoosh hit boom glitch riser sparkle type |

颜色用 `C.text / C.dim / C.faint / C.acc / C.accSoft / C.acc2 / C.bad / C.green / C.panel / C.panel2 / C.stroke`。字体用 `F.cn / F.en / F.mono`。

## 版面

- 顶部进度条在 y 150，小标签在 y 236，标题在 y 330（换行时第二行在 y≈420）。
- 内容区 y 480–1340；字幕框中心在 y 1420；右下角小窗圆心 (862, 1636)，半径 168。开场大窗在 y 150–712。
- 横向留 48 像素边距（48–1032）。两栏各宽 470，三行卡片每行高约 236–250、间距约 22–34。
- 每段的图一出现就完整（结构、卡片、文字都在），再随口播逐项点亮（黄色高亮、切分、数字滚动）。一个词对应一个点亮动作，不要先空着再一批字一下子冒出来；描述图的文字不能先于图出现。详见 [讲解表达](讲解表达.md)。
