# 参考视频拆解

目标是把「这个博主为什么好看」变成能照抄的具体动作（每屏几个字、几秒一切、开场三秒放什么），
写进自己下一条视频的脚本和画面里。

## 什么时候用哪条命令

| 情况 | 命令 |
| --- | --- |
| 给了抖音单条链接或博主主页 | `studio refs fetch <链接> [--limit 10]` → 存到 `creators/<作者>/` |
| 其他平台的单条（小红书、B 站等） | 手动放进 `saved/<YYYYMMDD 作者 标题>/source.mp4`，旁边放 `info.json` 或笔记 |
| 新视频进库后 | `studio refs jobs` 把新 mp4 补进 `jobs.tsv`，**先打开看一眼 slug、标题、分组对不对** |
| 跑拆解 | `studio refs run [slug…]`：转写 → 切镜 → 指标 → 视觉模型拆解，已有结果跳过 |
| 看汇总 | `studio refs report [分组…]` |
| 指标改了想重算 | `studio refs merge` |

目录在哪：`studio refs where`。布局写在仓库 `studio/refs/common.py` 开头。

## 判断要点

1. **先人工看两条再批量跑。** 指标看着像风格，实际可能是录屏卡顿或片头广告；先抽两条看缩略图拼版（`analysis/_sheets/`）。
2. **长视频只转前几分钟。** `jobs.tsv` 的 `asr_sec` 列填 420（7 分钟）够判断节奏，省转写费。
3. **数字以实测为准。** 语速、切镜频率、字幕长度来自转写和 ffmpeg 切镜，是可复现的；视觉模型给的「动画类型」「钩子类型」是看缩略图猜的，写结论时要标「模型判断」。
   - 不同转写服务分句粒度不同（Fun-ASR 一句比 whisper 长一倍左右），「每句字数」只在同一家转写的视频之间比。
   - 纯音乐、没人声的视频，whisper 会编出「词曲 某某」之类的假字幕；Fun-ASR 会如实返回 0 句。转写里出现这种字样先人工听一下。
4. **结论落到作者风格报告。** 每个博主一份 `analysis/<作者>_作者风格报告.md`：节奏数字、字幕样式、画面层、开场手法、可照抄的 5 条动作。
5. **只做个人学习。** 不转载、不二次分发原视频；引用画面时截图并注明作者。

## 成本

转写和拆解走哪家看 config 的 `[providers]`：asr 选 openai（约 0.006 美元/分钟）、bailian（Fun-ASR，约 0.8 元/小时）或 local（本机 whisper，免费）；vision 选 gemini 或 bailian（千问），每条一次调用。批量前先报条数和预计花费。
